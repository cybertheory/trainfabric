# MCP

Trainfabric exposes the same resolver over MCP so agents can discover, inspect, estimate, and query without custom glue.

## Endpoint

Streamable HTTP MCP (Cloudflare Agents + `@modelcontextprotocol/sdk`):

```
https://trainfabric-router.rishabhspro.workers.dev/mcp
```

| Method | Path |
|--------|------|
| `POST` / `GET` / `DELETE` | `/mcp` — MCP Streamable HTTP |
| `GET` | `/mcp/tools` — legacy tool list (JSON) |

**Production base**

```
https://trainfabric-router.rishabhspro.workers.dev
```

## Cursor / Claude config

```json
{
  "mcpServers": {
    "trainfabric": {
      "url": "https://trainfabric-router.rishabhspro.workers.dev/mcp"
    }
  }
}
```

Works with Cursor, Claude, MCP Inspector, and any Streamable HTTP MCP client. No local proxy required.

## Tools

| Tool | Purpose |
|------|---------|
| `discover_datasets` | Find datasets by intent / tags |
| `inspect_schema` | Schema + cheap filter hints |
| `estimate_query` | Cost / case estimate before running |
| `query_slice` | Exact column + filter query |
| `sample_dataset` | Peek at rows |
| `publish_dataset` | Ingest / publish |
| `check_job` | Poll async jobs |
| `create_derived_dataset` | Materialize derived tables |
| `preview_derived` | Preview a derived spec |
| `get_lineage` | Upstream / downstream lineage |
| `prompt_query` | Natural-language slice via Hermes + DuckDB skill |
| `start_auto` | Start long-running autoresearch (Box + Modal/HTTP GPU) |
| `check_auto` | Poll AutoRun status + trials |
| `list_auto_runs` | List AutoRuns for a dataset |
| `pause_auto` | Pause / resume / cancel an AutoRun |
| `post_social_update` | Publish a research finding / update to a dataset community (**auth required**) |
| `connect_dataset` | Connect (subscribe) the user to a dataset |
| `list_social_feed` | Recent community updates for connected datasets |

Querying (`query_slice`, `sample_dataset`, `prompt_query`) while authenticated auto-connects the user to that dataset.

## Auth

When Clerk is configured, pass `Authorization: Bearer <token>`. Otherwise anonymous access works for public datasets.

## Natural language (`prompt_query`)

Hermes runs inside the compute container with the `duckdb-analytics` skill. It:

1. Loads schema / partitions  
2. Estimates Case A/B  
3. Generates columns + filter (DuckDB-compatible)  
4. Optionally executes the slice  

LLM calls go through **Cloudflare AI Gateway** (`CF_ACCOUNT_ID` + `CF_AI_GATEWAY_TOKEN`). Without gateway credentials, a schema-grounded heuristic planner is used.

REST equivalent: `POST /datasets/:id/prompt` with `{ "prompt": "...", "execute": true }`.

## Autoresearch (`start_auto`)

Long campaigns are a separate primitive from `prompt_query`:

1. Control plane creates an **AutoRun** with an immutable experiment protocol (frozen snapshot, metric, budget, mutable/immutable paths).
2. A [Box](https://box.ascii.dev/) sandbox is forked from a template and runs the Trainfabric autorunner daemon (git + `/prompt` + trial enqueue).
3. GPU trials go to **Modal** or a self-hosted **HTTP runner** (`POST /runners/register`, poll `/runners/claim`). No SSH.

REST: `POST /datasets/:id/auto`, `GET /auto/:id`, dashboard monitor at `/auto/:id`.

See `services/autorunner/README.md` for the daemon and GPU worker image.
