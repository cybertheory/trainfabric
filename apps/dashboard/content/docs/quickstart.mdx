# Quickstart

## 1. Connect MCP

Add this MCP server to your agent client:

```
https://trainfabric-router.rishabhspro.workers.dev/mcp
```

List tools:

```bash
curl https://trainfabric-router.rishabhspro.workers.dev/mcp/tools
```

## 2. Discover a dataset

Ask your agent to call `discover_datasets` with an intent, or browse the [public catalog](/datasets).

## 3. Query a slice

Use `query_slice` (MCP) or `POST /datasets/:id/query` (REST) with columns + filters. Partition-aligned reads skip compute; identical queries hit cache.

## 4. Publish (optional)

Use [Publish](/new) in the dashboard or `publish_dataset` via MCP. Set `visibility` to `private` for internal infra, or `public` to share.

Sources: **upload**, **public Hugging Face / GitHub URL**, or **Connect & pull** (GitHub App install or Hugging Face OAuth) for private/gated tabular files.
