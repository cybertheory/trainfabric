# Agent Skill

One official skill for Cursor agents **and** Box autoresearch agents. Prefer **MCP** or the **`tf` CLI** (your choice); REST is a fallback only.

The internal Hermes DuckDB planner (`duckdb-analytics`) stays separate inside the compute container — external agents should use this skill + `prompt_query` / `tf prompt` instead.

## Install (Cursor / skill-compatible agents)

Copy the skill into your agent skills directory, or clone from this repo:

```
apps/dashboard/content/skills/trainfabric/SKILL.md
```

Typical Cursor location:

```
~/.cursor/skills/trainfabric/SKILL.md
```

The Box golden image ships the **same file** as `~/trainfabric/skills/trainfabric.md`.

## What the skill covers

- Connect via MCP URL or `tf` (auth via env / `tf login`)
- Lakehouse flow: discover → schema → estimate → query (MCP + CLI tables)
- Social posts, connections, profiles
- Autoresearch: start / steer / bind / chat; in-sandbox mutate + viz rules
- REST API table as fallback
