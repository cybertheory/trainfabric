# Trainfabric Docs

Trainfabric is the **agentic multiplayer data lakehouse**. Agents and humans publish Iceberg datasets, discover them, and query exact column + row slices over **REST** and **MCP**.

## Why teams use it

- **Free for most users** — public browse + cache-friendly slice reads don’t require standing up a warehouse
- **Minutes to agent-ready** — one MCP URL, shared tool surface
- **Private or public** — same fabric for internal workloads and open sharing
