# API

Base URL:

```
https://trainfabric-router.rishabhspro.workers.dev
```

All routes below are relative to that host. Dashboard local proxy: `/api/proxy`.

## Health

```
GET /health
```

## Datasets

| Method | Path | Notes |
|--------|------|-------|
| `GET` | `/datasets` | List / search (`search`, `tag`, `owner`) |
| `GET` | `/datasets/:id` | Metadata |
| `GET` | `/datasets/:id/schema` | Schema contract |
| `GET` | `/datasets/:id/snapshots` | Iceberg snapshots |
| `GET` | `/datasets/:id/lineage` | Lineage graph |
| `POST` | `/datasets` | Publish / ingest |
| `POST` | `/datasets/derived` | Create derived dataset |
| `POST` | `/datasets/:id/query` | Query slice |
| `POST` | `/datasets/:id/estimate` | Estimate query |
| `POST` | `/datasets/:id/sample` | Sample rows |
| `POST` | `/datasets/:id/prompt` | Hermes NL → DuckDB slice |
| `POST` | `/datasets/:id/rebuild` | Rebuild derived |
| `GET` / `POST` | `/datasets/:id/connect` | Connection status / toggle (subscribe) |
| `GET` | `/me/connections` | List connected datasets |

## Social feed & notifications

| Method | Path | Notes |
|--------|------|-------|
| `GET` | `/social/feed` | Feed for connected datasets (auth optional; global if none) |
| `POST` | `/social/posts` | Create update (`datasetId`, `body`, optional `findings`, `source`) — **auth required** |
| `GET` | `/social/posts/:id` | Single post |
| `GET` | `/notifications` | Server notifications for connected-community updates |
| `POST` | `/notifications/:id/read` | Mark one read |
| `POST` | `/notifications/read-all` | Mark all read |

Querying or sampling a dataset while authenticated **auto-connects** you to that dataset community.

## Example: query

```bash
curl -X POST https://trainfabric-router.rishabhspro.workers.dev/datasets/<id>/query \
  -H 'content-type: application/json' \
  -d '{
    "columns": ["pickup_date", "fare_amount"],
    "filter": "pickup_date = '\''2024-01-01'\''"
  }'
```

Identical queries return cached results. Partition-aligned filters can resolve to zero-compute (presigned ranges).
